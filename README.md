# Glass Launcher (final)
Kotlin + Jetpack Compose. Deschide în Android Studio -> Run -> Home -> alege "Glass Launcher" -> Always.

Funcții:
- Glass cu blur real al wallpaper-ului (merge pe toate versiunile Android)
- Long-press pe aplicație: Add/Remove home, Add/Remove dock, App info, Uninstall
- Long-press pe fundal: Choose wallpaper / Use system wallpaper
- Swipe up sau lupa: sertar de aplicații cu căutare
- Ceas, dată, baterie live; tap pe widget-uri deschide Ceas / Calendar / Baterie
- Tasta Home închide sertarul și meniurile
